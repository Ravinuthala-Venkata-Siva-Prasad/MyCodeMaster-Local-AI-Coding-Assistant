# MyCodeMaster – AI Coding Assistant 🤖

MyCodeMaster is a local AI coding assistant built using Python, Gradio, and Ollama. It helps users write code, understand programming concepts, and get answers to coding questions.

## 🚀 Features

* AI-powered coding assistance
* Local LLM using Ollama
* Interactive Gradio interface
* Programming explanations and code generation

## 🛠️ Technologies

* Python
* Ollama
* Gemma 3
* Gradio
* Requests

## ⚙️ Installation

Install the required packages:

```bash
pip install requests gradio
```

Create the custom Ollama model:

```bash
ollama create MyCodeMaster -f modelfile
```
